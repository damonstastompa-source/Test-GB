# My God Box v3.0.0

Test build based directly on the current My God Box v1.3.3 baseline.

This build keeps the existing icon, themes, visual identity, and core home experience while adding the agreed v3 workflow:
- Turn It Over / Reflect / Quiet Place drawer
- Settings and About anchored at the bottom
- Themes inside Settings
- My Entries toggle for Turned Over / Reflections
- Search and contained scrolling
- Multiple reflections linked to one Turned Over entry
- Reflection prompt dropdown with No prompt
- Add reflection from a Turned Over item
- Delete and Burn, with reflections preserved
- Collapsible How to Install in About

Version: 3.0.0
