# My God Box — v3.0.1

A local-first, mobile-friendly web app for writing down what you cannot control, turning it over, and optionally reflecting.

## 3.0.1 test build
- Restores **Look Inside** as the unified Turned Over / Reflections record screen.
- Places **Look Inside** immediately above **Quiet Place** in the drawer.
- Keeps the existing icon and the four existing themes unchanged.
- Moves Themes into Settings.
- Turn It Over and Reflect open focused, theme-fitting popups rather than separate writing pages.
- Long writing scrolls inside the popup without moving the page behind it.
- Look Inside keeps search and uses a contained scrolling entry list so the whole page does not scroll through entries.
- Turned Over and Reflections can be linked together.
- Multiple reflections can be attached to one Turned Over item.
- Burning a Turned Over item asks for confirmation and removes only that item; connected reflections remain with their original context preserved.
- Reflection prompts use a dropdown, including **No Prompt**.
- About includes a collapsible **How to install** card and displays v3.0.1.
- No download/ZIP control was added to Settings.

Keep the existing `icon-192.png` and `icon-512.png` files from the working repository unchanged when moving this test build into a test repository.
