# My God Box

My God Box is a local-first, mobile-friendly web app for writing down what you cannot control, turning it over, and optionally reflecting.

## v2.0.2
- Uses the full My God Box logo as favicon, Apple touch icon, and PWA icon.
- Replaced bottom navigation with a single slide-out menu to avoid duplicate navigation.
- Added obvious home links and a dedicated **My Reflections** screen.
- Saved reflections can be opened, read, searched, and deleted.
- Backup includes entries, reflections, theme, and app version.
- Export and Print/PDF include both entries and reflections.
- Everything remains local unless you explicitly export it.

## GitHub Pages
1. Upload the contents of `my-god-box/` to a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save. GitHub Pages will publish the app.

No build step is required.


## GitHub Pages deployment
For a repository publishing from the root of `main`, upload the **contents of this folder** to the repository root (where `index.html` lives). Do not upload the `my-god-box` folder as a subfolder. After committing, open the site in a private/incognito tab or hard-refresh once.
