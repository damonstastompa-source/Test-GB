# My God Box v1.4.1 test build

This test build is based on the working v1.3.3 app.

Replace these three files in a copy of the working repository:
- index.html
- app.js
- styles.css

Keep the existing image, manifest, and other files unchanged.

Changes in this build:
- Menu simplified to Turn It Over / Reflect / Quiet Place, with Settings and About anchored at the bottom.
- Themes moved inside Settings.
- Turn It Over and Reflect use the existing themed popup workflow.
- Reflect screen uses the existing My Entries layout with Turned Over / Reflections toggle and search.
- Subtle add actions appear at the bottom of the selected list.
- Reflection prompts are a dropdown, including No prompt.
- Reflections can be linked to a turned-over entry.
- Viewing a turned-over entry can open a linked reflection.
- Burn removes turned-over entries while leaving reflections behind.
- Long writing is read inside a scrollable themed reading box instead of making the whole page move.
- Quiet Space is fixed/non-scrollable.
- About includes a collapsible How to install card.
- Version is v1.4.1.
- No white text boxes; all fields stay theme-matched.
